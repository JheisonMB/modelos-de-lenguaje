# De la atención a los agentes

Infografía interactiva sobre los modelos de lenguaje, 2017–2026: línea de tiempo, la brecha entre modelos abiertos y cerrados, las perillas de muestreo (temperatura, top-p, top-k, esfuerzo) y el debate del loro estocástico.

**Ver:** https://jheisonmb.github.io/modelos-de-lenguaje/

Sitio estático sin build: `index.html` + `styles.css` + `app.js` (render) + `data.js` (contenido). Para editar el contenido basta con tocar `data.js`.

```bash
python3 -m http.server 8000   # los módulos ES requieren servirse por HTTP
```
