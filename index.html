03

Las perillas

El modelo no elige una palabra: calcula una probabilidad para cada candidata. Estos parámetros deciden cómo se escoge entre ellas.

Siguiente palabra para El cielo es ___

pi = ezi/T / Σj ezj/T

z son los logits: la puntuación cruda de cada candidata. Dividir por T antes del softmax estira o encoge las diferencias.

Regla práctica: temperatura baja (0–0,3) para extraer datos, clasificar o programar; media (0,7–1) para conversar; alta (>1) para lluvia de ideas, con riesgo de incoherencia.

    La tesis · 2021

    «Un loro estocástico»

    Un sistema que cose secuencias de formas lingüísticas observadas en sus datos, según información probabilística, sin ninguna referencia al significado.

    Bender, Gebru, McMillan-Major y Mitchell (FAccT 2021). El artículo advertía además de sesgos heredados, costo ambiental y la ilusión de comprensión en quien lee.
